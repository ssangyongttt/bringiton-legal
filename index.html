다덤벼 개인정보처리방침

시행일 2026년 9월 6일 · 버전 1.2

01수집하는 개인정보 항목

서비스는 아래 항목을 수집합니다. 회원가입 절차가 없으므로 이름, 생년월일, 연락처, 이메일 주소는 수집하지 않습니다.

02개인정보의 처리 목적

  • 게임 진행 — 게임방 생성·참가, 실시간 라운드 동기화, 승패 판정 및 결과 제공
  • 이용자 구분 — 같은 방에 참여한 이용자를 서로 구분하고 결과를 표시
  • 기록 제공 — 전적, 칭호, 게임별 기록 등 이용자 본인의 이용 내역 제공
  • 서비스 운영 — 부정 이용·비정상 접속 차단, 오류 원인 분석 및 서비스 개선
  • 이용 분석 — 어떤 화면과 기능이 이용되는지 통계적으로 분석하여 서비스를 개선. 개별 이용자를 식별하거나 추적하지 않으며, 통계 형태로만 이용합니다.
  • 광고 게재 — 앱 내 광고 노출 및 성과 측정
  • 알림 발송 — 이용자가 동의한 경우에 한해 방 초대, 친구 요청, 게임 결과, 공지 알림 발송

  • 이용자가 사전에 동의한 경우
  • 법령에 따라 요구되거나, 수사기관이 적법한 절차에 따라 요청한 경우

07광고와 푸시 알림

광고

서비스는 한 판을 모두 마치고 나갈 때 전체 화면 광고 한 번만 게재합니다. 게임 진행 중이나 라운드 사이에는 광고를 노출하지 않으며, 화면 하단의 배너 광고는 사용하지 않습니다. 보상형 동영상 광고도 사용하지 않습니다.

처음 이용하시는 분께는 첫 판이 끝날 때 광고를 노출하지 않습니다.

광고 게재를 위해 기기의 광고 식별자를 사용하며, 이용자는 아래 방법으로 직접 제한할 수 있습니다.

  • Android — 설정 → Google → 광고 → 광고 ID 삭제 또는 재설정
  • iOS — 설정 → 개인정보 보호 및 보안 → 추적 → 앱의 추적 요청 허용 끄기

광고 식별자 사용을 제한해도 게임 이용에는 아무런 제한이 없으며, 노출되는 광고의 관련성만 낮아집니다.

신고와 차단

다른 이용자의 닉네임이 부적절한 경우 신고할 수 있고, 특정 이용자를 차단하여 보이지 않게 할 수 있습니다. 신고 기록에는 신고한 사람과 신고당한 사람의 익명 식별자가 남으며, 중복 신고를 걸러내는 목적으로만 사용합니다.

서로 다른 이용자 여러 명이 같은 닉네임을 신고한 경우, 회사는 그 닉네임을 초기화할 수 있습니다. 초기화되면 다음 접속 때 새 닉네임을 정하게 되며, 게임 기록은 지워지지 않습니다.

이때 서버는 초기화된 시각만 보관하고, 기기에 저장된 닉네임은 앱이 다음에 실행될 때 앱 스스로 지웁니다. 회사가 이용자의 기기 저장소에 직접 접근하지는 않습니다.

“내 데이터 삭제”를 실행하면 회원님이 신고한 기록도 함께 삭제됩니다.

푸시 알림

푸시 알림은 이용자가 동의한 경우에만 발송하며, 동의 시 푸시 등록 토큰이 발급됩니다. 수신 동의는 언제든지 철회할 수 있습니다.

  • 앱에서 — 설정 → 알림 설정에서 전체 또는 항목별(방 초대 / 친구 요청 / 게임 결과·칭호 / 공지·이벤트)로 끌 수 있습니다.
  • 기기에서 — 운영체제의 앱별 알림 설정에서 전체 차단할 수 있습니다.

알림 수신을 거부해도 게임 이용에는 제한이 없습니다. 다만 방 초대 알림을 끄면 친구가 부를 때 알림을 받지 못합니다.

이용 분석

서비스 개선을 위해 어떤 화면과 기능이 이용되는지 통계적으로 수집합니다. 수집 목적은 통계 분석에 한정되며, 개별 이용자를 식별하거나 다른 앱·웹사이트에서의 활동을 추적하지 않습니다.

08이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 열람·정정·삭제·처리정지를 요구할 수 있습니다.

앱에서 직접 처리하는 방법

  • 닉네임·아바타 변경 — 설정 → 프로필 편집
  • 전체 데이터 삭제 — 설정 → 내 데이터 삭제. 익명 인증 식별자와 이에 연결된 게임 기록이 즉시 삭제되며, 삭제 후에는 복구할 수 없습니다.
  • 앱 삭제 — 기기에서 앱을 삭제해도 서버에 저장된 익명 식별자는 위 3항의 기간(최종 접속일로부터 90일)이 지나면 자동 삭제됩니다. 즉시 삭제를 원하시면 앱 삭제 전에 “내 데이터 삭제”를 이용해 주십시오.

문의를 통한 방법

아래 13항의 문의처로 요청하실 수 있습니다. 다만 서비스는 회원가입 정보를 보유하지 않아 본인 확인이 불가능하므로, 요청 시 앱 설정 화면에 표시되는 익명 식별자를 함께 알려주셔야 처리할 수 있습니다.

09개인정보의 파기

  • 파기 절차 — 보유 기간이 경과하거나 처리 목적이 달성된 개인정보는 별도의 승인 절차 없이 자동 삭제 작업을 통해 파기합니다.
  • 파기 방법 — 전자적 파일 형태의 정보는 복구·재생할 수 없는 기술적 방법으로 영구 삭제합니다.

10안전성 확보 조치

  • 전송 구간 암호화 — 앱과 서버 간 모든 통신을 TLS로 암호화합니다.
  • 접근 권한 관리 — 데이터베이스 행 수준 보안(RLS) 정책을 적용하여, 이용자가 자신과 무관한 데이터에 접근할 수 없도록 제한합니다.
  • 최소 수집 — 서비스 제공에 필요한 최소한의 정보만 수집하며, 직접 식별 정보를 수집하지 않습니다.
  • 접근 기록 보관 — 개인정보 처리 시스템의 접속 기록을 보관·점검합니다.

11만 14세 미만 아동

서비스는 만 14세 이상을 대상으로 합니다. 「개인정보 보호법」에 따라 만 14세 미만 아동의 개인정보를 처리하려면 법정대리인의 동의가 필요하나, 서비스는 회원가입 절차가 없어 법정대리인 동의를 확인할 수 없으므로 만 14세 미만 아동은 서비스를 이용할 수 없습니다.

만 14세 미만 아동의 개인정보가 수집된 사실이 확인되는 경우, 지체 없이 해당 정보를 파기합니다.

12방침의 변경

법령·서비스 내용의 변경에 따라 본 방침이 수정될 수 있습니다. 내용이 추가·삭제·수정되는 경우 변경 사항 시행 7일 전부터 앱 내 공지사항을 통해 안내합니다. 다만 이용자의 권리에 중대한 변경이 있는 경우에는 최소 30일 전에 안내합니다.
